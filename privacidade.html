Política de Privacidade

Última atualização: 10 de setembro de 2026

1. Responsável pelo Tratamento

A A-Design Angola (doravante "nós"), marca da A.Academy, é responsável pelo tratamento dos teus dados pessoais através do site adesignangola.ao.

Para questões relacionadas com privacidade, podes contactar-nos via WhatsApp ou email indicados no site.

2. Dados que Recolhemos

Recolhemos apenas os dados estritamente necessários para o funcionamento do serviço:

  • Dados de inscrição: nome completo, email, telefone (WhatsApp), cidade
  • Dados do perfil: informações específicas conforme o perfil selecionado (igreja, empresa, freelancer, pessoal)
  • Dados de pagamento: registo de estado de pagamento (não armazenamos dados de cartão de crédito)
  • Dados de navegação: cookies estritamente necessários para o funcionamento do site
  • Dados analíticos: apenas se autorizares o uso de cookies analíticos (tráfego, páginas visitadas, dispositivo)

3. Finalidade do Tratamento

Os teus dados são utilizados exclusivamente para:

  • Processar a tua inscrição no curso
  • Confirmar e gestionar pagamentos
  • Communicar contigo sobre o estado da inscrição
  • Fornecer acesso ao grupo da turma
  • Gerir o painel administrativo (apenas para administradores)
  • Melhorar o site e a experiência do utilizador (apenas com consentimento)

4. Base Legal

O tratamento dos teus dados é baseado em:

  • Execução de contrato: processamento da inscrição e prestação do serviço
  • Consentimento: para cookies analíticos e de marketing
  • Interesse legítimo: para melhoria do serviço e prevenção de fraude

5. Partilha de Dados

Não vendemos nem partilhamos os teus dados pessoais com terceiros para fins de marketing.

Os dados podem ser partilhados com:

  • Supabase: plataforma de hosting da base de dados (dados armazenados em servidores seguros)
  • Netlify: plataforma de hosting do site
  • Apenas em caso de obrigação legal

6. Armazenamento e Segurança

Os teus dados são armazenados em servidores seguros com as seguintes proteções:

  • Cifragem em trânsito (HTTPS/TLS)
  • Controlo de acesso restrito (Row Level Security no Supabase)
  • Registo de auditoria de ações administrativas

Os dados de inscrição são mantidos durante o período necessário para a prestação do serviço e por até 2 anos após a conclusão do curso, para efeitos de suporte.

7. Os Teus Direitos

De acordo com a Lei Geral de Proteção de Dados (LGPD) e regulamentos aplicáveis, tens direito a:

  • Acesso: saber quais dados temos sobre ti
  • Retificação: corrigir dados incorretos
  • Eliminação: solicitar a remoção dos teus dados
  • Portabilidade: receber os teus dados em formato estruturado
  • Oposição: opor-te ao tratamento dos teus dados
  • Revogação do consentimento: a qualquer momento, para dados tratados com base em consentimento

Para exercer estes direitos, contacta-nos através dos meios indicados no site.

8. Cookies

Utilizamos cookies para o funcionamento do site e, apenas com o teu consentimento, para analytics e marketing.

Consulte a nossa Política de Cookies para mais detalhes.

9. Menores de Idade

O site não é dirigido a menores de 16 anos. Se soubermos que recolhemos dados de um menor, procederemos à sua eliminação imediata.

10. Alterações

Esta política pode ser atualizada periodicamente. A data da última atualização está indicada no topo desta página. Recomendamos a consulta regular.

11. Contacto

Para questões sobre privacidade ou para exercer os teus direitos, contacta-nos:

  • WhatsApp: indicado no site
  • Email: contacto disponível no site
